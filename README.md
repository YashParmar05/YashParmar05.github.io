# Yash Parmar — GitHub Pages Portfolio

A simple static portfolio built with only:
- HTML
- CSS
- JavaScript

No Node.js, npm, React, or build step is required.

## GitHub Pages

Create a repository named:

`YashParmar05.github.io`

Upload the contents of this folder to the repository root.

Then enable:
Settings → Pages → Deploy from branch → main → / (root)

Your website will be available at:

`https://YashParmar05.github.io`

## Optional images

The website works without any additional images because fallback initials are built in.

You can add:
- `assets/profile.jpg`
- `assets/quantumbot-logo.png`
- `assets/national-games-logo.png`
- `assets/uoh-logo.png`
- `assets/gtu-logo.png`

If a logo/photo is missing, the site automatically shows a text fallback.

## Resume

Replace `assets/Yash_Parmar_Resume.pdf` whenever you update your resume.
